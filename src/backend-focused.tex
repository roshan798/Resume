\item \href{https://github.com/roshan798/pizza-delivery-app}{\textbf{Pizza Delivery Platform}}
  \hfill \href{https://mern-pizza-app.cyou}{mern-pizza-app.cyou}\\
  Production-grade, multi-tenant pizza ordering platform built across
  \textbf{5 independently deployed Node.js microservices}.
  \begin{itemize}
    \itemsep -3pt
    \item Architected \textbf{role-based authentication} (Admin / Manager / Customer)
          in a dedicated Auth Service backed by \textbf{PostgreSQL};
          implemented JWT access + refresh token rotation with HTTP-only cookies;
          downstream services validate tokens locally via shared secret,
          removing Auth Service as a synchronous dependency and eliminating it
          as a single point of failure.
    \item Built an \textbf{event-driven product price cache} in Order Service by
          consuming \textbf{Apache Kafka} events (PRODUCT\_UPDATED, TOPPING\_UPDATED)
          published by Catalog Service --- removes cross-service HTTP calls at
          checkout and ensures price validation remains available even during
          Catalog Service downtime.
    \item Integrated \textbf{Stripe PaymentIntent} API with webhook signature
          verification (\texttt{POST /payments/webhook}); order status transitions
          to PAID only after cryptographic confirmation from Stripe,
          preventing duplicate charges on network retries.
    \item Designed a 9-event Kafka topology across 3 topics (catalog, orders,
          payments) enabling fan-out: a single ORDER\_PLACED event is independently
          consumed by WebSocket Service (real-time UI push) and Notification Service
          (email delivery) with no coupling between consumers.
    \item Deployed on \textbf{AWS EKS} managed by \textbf{ArgoCD v3.3.2} (GitOps);
          GitHub Actions builds Docker images on push, updates K8s manifests;
          NGINX Ingress handles SSL termination, CORS headers, and path-based
          routing; 3 replicas for Order Service for peak-load tolerance.
    \item \textbf{Tech:} Node.js \(\cdot\) PostgreSQL \(\cdot\) MongoDB \(\cdot\)
          Apache Kafka \(\cdot\) Stripe \(\cdot\) Socket.io \(\cdot\) AWS S3 \(\cdot\)
          Kubernetes \(\cdot\) Docker \(\cdot\) ArgoCD \(\cdot\) NGINX \(\cdot\)
          Next.js \(\cdot\) React
  \end{itemize}
